パーソナルジム／ 静的ランディングページ

FORMA

料金プランの比較シミュレーターと、スクロールに応じて数字が動く実績表示を組み込んだ1ページ構成です。

実サイトを見る（別タブ）
種別パーソナルジム／架空の店舗を想定した自主制作
担当範囲企画・デザイン・実装
使用技術HTML ／ CSS（BEM設計）／ JavaScript ／ Swiper
構成1ページ（ランディングページ）

ランディングページの順番

1ページで完結させる以上、読む順番がそのまま説得の順番になります。悩みへの共感 → 解決できる根拠 → 実績 → 料金 → よくある不安 → 申し込み、という流れで構成しました。

料金を先に見せる

パーソナルジムは高額なため、料金が分からないと問い合わせに至りません。回数と期間を選ぶと総額と月々の負担が出るシミュレーターを置き、「思ったより高い／安い」を先に判断してもらう形にしました。

数字を印象づける

実績の数字は、画面に入ったタイミングで0から動いて表示されます。ただ書いてあるより目に留まるためですが、動きを減らす設定にしている環境では動かさないようにしています。
